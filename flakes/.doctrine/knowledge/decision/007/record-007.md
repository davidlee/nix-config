`modules.<class>` folds over `features/default.nix` then each area index in list order (never `attrNames`, ADR-002 D5). For each selected feature whose descriptor has the class (presence test only), it emits `{ _file = "features/<area>/<name>#<class>"; imports = [ descriptor.<class> ]; }` (ADR-002 D6). The resolver reads only `enable`, `requires` and `? <class>`; it never imports or applies a class value (ADR-002 D4). ADR-005 D6 is a generated assertion: a selected feature with no class among the host's `classes` fails. Factories append: mkNixos `[config.nix overlay] ++ modules.nixos`; mkHome `[home.nix overlay] ++ modules.homeManager`; mkDarwin `[rev config.nix] ++ modules.darwin` (no embedded-HM hook, DEC-001). Snooze moves to factory depth; expected derivation-identical because it contributes to no shared list; the drvs/drvs-sets gates decide.
