`modules.<class>` folds over `features/default.nix` then each area index in list order (never `attrNames`, ADR-002 D5). For each selected feature whose descriptor has the class (presence test only), it emits `{ _file = "features/<area>/<name>#<class>"; imports = [ descriptor.<class> ]; }` (ADR-002 D6). The resolver reads only `enable`, `requires` and `? <class>`; it never imports or applies a class value (ADR-002 D4). ADR-005 D6 is a generated assertion: a selected feature with no class among the host's `classes` fails. Factories append (module lists as of DEC-016, SL-004): mkNixos `[config.nix platformModule] ++ modules.nixos`; mkHome `[homeModule home.nix] ++ modules.homeManager`; mkDarwin `[rev config.nix platformModule] ++ modules.darwin`. Snooze moves to factory depth; expected derivation-identical because it contributes to no shared list; the drvs/drvs-sets gates decide.
