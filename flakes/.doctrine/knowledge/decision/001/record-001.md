New feature `enable` options default false. The outer profile `features/profiles/workstation.nix` sets `feature.session.snooze.enable = mkDefault true`; Sleipnir imports it, the Mac imports no profile, so darwin no longer selects snooze. Effective behaviour is unchanged (ADR-001 D7) and ADR-005 D6 holds without platform metadata. `mkDarwin` projects the `darwin` class only; darwin's embedded Home Manager gets no projection until a feature needs one.
