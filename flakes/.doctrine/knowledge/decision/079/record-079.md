The interactive daemon's room door file is rendered by home-manager in flakes (features/satan/room.nix via runner.nix) to ~/.config/malebolge/door.toml, a stable path. Its schema is part of the contract: one [door] table with exactly the keys room, user, known_hosts, host_key_alias, identity and home (satan ROOM_DOOR_KEYS plus home), all strings. The daemon refuses any other key (onlyKeys), so adding a key on the flakes side breaks the daemon at startup; a schema change is made on both sides together. host_key_alias = room-assistant.
