An outer profile is an ordinary module of the outer evaluation, in `features/profiles/<name>.nix`, setting only `mkDefault` values on `feature.*` (ADR-001 D3). A host selects profiles by importing them from `hosts/<host>/features.nix`, so host → profile is visible in the host file (ADR-001 D1). A host may import several; profiles may import profiles. Equal-priority disagreement between profiles is an evaluation error, which the host settles with a plain definition; host definitions always beat profile defaults. The resolver never lists `features/profiles/`, so it is not an area. First profile: `workstation`, setting `feature.session.snooze.enable = mkDefault true`; Sleipnir imports it, the Mac imports none (DEC-001).
