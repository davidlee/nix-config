`features/default.nix` is a list of `{ name; value; }` areas, and each `features/<area>/default.nix` is a list of `{ name; value; }` features, so `builtins.listToAttrs` builds the tree and the lists give the projection order (ADR-002 D2, D5). Depth is fixed at two: `<area>.<name>`. Areas are ordered `hardware`, `session`, matching the current gated NixOS order (openrgb before snooze). Snooze becomes a directory, `features/session/snooze/` (`default.nix`, `nixos.nix`, `home.nix`, `bin/snooze-nag`, `bin/snooze-nag-test`); the script and its test move together. openrgb moves to `features/hardware/openrgb.nix`.
