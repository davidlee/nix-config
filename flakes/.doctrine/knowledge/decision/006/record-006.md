`features.nix` is `lib: { tree, classes, system, modules } -> { modules }`. It evaluates the generated `feature.<area>.<name>.enable` options, an `assertions` option (NixOS shape: `{ assertion; message; }`) and the host's modules. Assertions = hand-written ++ generated (`requires` per DEC-005; ADR-005 D6 'projects nothing'; a `platforms` list that omits `system`, DEC-030). If any fail it `throw`s one message listing every failure; otherwise it returns `{ modules = { nixos; homeManager; darwin; }; }`. The whole result is guarded, so any access fails. `hosts.nix` computes `selections` once per host (classes from meta.nix: its kind, nixos or darwin [+ homeManager when home = true]; `system` from meta.nix) and every factory takes `selections.<host>`, so NixOS, home-only and darwin builds fail identically (ADR-001 D5). `throw` rather than `abort`, so tests can use `builtins.tryEval`.

Updated at SL-008 `/reconcile` (RV-018 F-15): the signature gained `system` (SL-008 P1), and the legacy `flags` result (`specialArgs.features`, DEC-002) is gone since the flags were retired.
