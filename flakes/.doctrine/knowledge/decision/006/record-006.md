`features.nix` becomes `lib: { tree, classes, modules }: …`. It evaluates legacy flag options, generated `feature.<area>.<name>.enable` options, an `assertions` option (NixOS shape: `{ assertion; message; }`) and the host's modules. Assertions = hand-written ++ generated (`requires` per DEC-005; ADR-005 D6 'projects nothing'). If any fail it `throw`s one message listing every failure; otherwise it returns `{ flags; modules = { nixos; homeManager; darwin; }; }`, where `flags` is the config minus `feature` and `assertions` (becomes `specialArgs.features`, DEC-002). The whole result is guarded, so any access fails. `hosts.nix` computes `selections` once per host (classes from meta.nix: its kind, nixos or darwin [+ homeManager when home = true]) and every factory takes `selections.<host>`, so NixOS, home-only and darwin builds fail identically (ADR-001 D5). `throw` rather than `abort`, so tests can use `builtins.tryEval`.
