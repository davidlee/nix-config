A descriptor may carry `requires = [ "<area>.<name>" … ]`. For every selected feature, the resolver asserts each required feature is selected in the final merged selection (host plus profiles), and fails naming the dependent and the missing prerequisite. It does not matter how the prerequisite came to be off (explicit false or default false); no option-priority inspection. The resolver never selects anything: profiles select prerequisites alongside their dependents with `mkDefault`. This is stricter than ADR-001 D4's wording ("may default a prerequisite on … explicit false is an error") and SL-001 proposes amending D4 to match. An unknown path in `requires` is itself an error.
